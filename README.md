# Plastic Jungle

Static label site for plasticjungle.world. No build step: open `index.html` or serve the folder.

- `config.js` holds releases, socials, contact and the Mailchimp form URL. Add a release by adding an object to `releases`.
- Cover art goes in `assets/covers/` and is referenced from the release's `cover` field.
- Links with an empty `url` show as "(soon)".
- `assets/arketyp.svg` is the Arketyp wordmark from arketyp.se, rotated to horizontal.
